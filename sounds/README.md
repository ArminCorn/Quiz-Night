# Sounds

Hier kommen die Audiodateien hinein. Der Dateiname (ohne Endung) ist der Name des Sounds.

| Datei (Beispiel)    | Wann er spielt                                     |
|---------------------|----------------------------------------------------|
| `formatIntro.mp3`   | Ein Format startet (Intro-Screen)                  |
| `reveal.mp3`        | Kategorien: eine Kategorie wird aufgedeckt         |
| `roundEnd.mp3`      | Kategorien: ein Team holt den Rundenpunkt          |
| `scoreUpdate.mp3`   | Zwischenstand: Punkte wandern in den Gesamtstand   |
| `buzz.mp3`          | Ein Team hat gebuzzert                             |
| `correct.mp3`       | Richtige Antwort (z. B. Länderraten)               |
| `wrong.mp3`         | Falsche Antwort (z. B. Länderraten)                |

- Erlaubte Endungen: `.mp3`, `.ogg`, `.wav`, `.m4a`, `.aac`, `.webm`, `.flac`
- Groß-/Kleinschreibung beachten: `roundEnd.mp3`, nicht `roundend.mp3`.
- Fehlt eine Datei, passiert einfach nichts.
- Neue Dateien werden beim nächsten Neuladen des Beamer-Fensters erkannt (kein Neustart nötig).
- Sounds spielen nur im Beamer-Fenster. Damit der Browser Ton erlaubt, einmal in das Beamer-Fenster klicken.
